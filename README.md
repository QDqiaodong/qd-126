# 企业园区接待室影音设备多楼层归属流转台账系统

## 项目简介

本系统用于企业园区行政统一管理接待室电视、音响、麦克风等影音设备，支持跨楼层、跨接待室调配流转，并维护设备长期调配台账。

同时提供**盘点批次工作台**：管理员按楼层或接待室创建盘点任务并生成创建时刻的设备快照，现场逐台标记「在场 / 缺失 / 位置不符 / 待维修」并填写备注；提交时冻结当前台账作为差异基准并产出差异清单，位置不符设备可直接跳转调配（复用设备调配并写入流转记录），缺失/待维修设备登记处理结果并保留处理状态。支持批次列表、进度、详情与关闭，同一批次设备不重复，已关闭批次不可修改，刷新后快照与台账差异保持一致。

同时提供**接待室活动占用登记**：管理员按楼层选择接待室，登记活动名称、开始/结束时间、预计使用的影音设备和负责人；同一接待室时段重叠直接拦截，活动进行中的设备不得再调配到其他接待室（设备编辑跨房间同样拦截）；支持按日期、楼层、状态筛选活动，活动详情展示占用设备清单与冲突提示（时段重叠、设备被调走、设备异常）；活动到期自动释放占用，也可手动提前结束释放，刷新后接待室占用状态、设备归属与活动列表保持一致。

同时提供**接待室静音时段管控**：行政按接待室登记静音起止时间与原因（可改可删），并按楼层筛选查看；新建或修改活动占用时，时段与该室静音重叠即弹出静音原因并拦截提交（专用业务码 460），未设静音的接待室不受影响可正常占用；待开始活动可编辑时段/设备/负责人，已开始或已结束的活动不改历史，仅在其详情冲突提示中标注与静音时段的重叠及原因。

同时提供**常用影音组合一键套用**：管理员把常用的电视/音响/麦克风等设备保存为命名的影音组合（可启停、增删改）；值班员选择接待室一键套用，系统只把空闲（未上墙、状态正常、未被进行中活动占用）的组合设备调入，已经在别的接待室使用、待修、损坏或被进行中活动占用的设备自动跳过并逐台写明原因，套用前已在房间的设备标记为「已在房间」；套用结果展示调入/已在/跳过统计、逐台原因及套用前后房间设备清单对照，调入设备同步写入设备流转台账，并校准接待室设备数量；套用记录持久化，详情页对调入/已在设备附带实时台账位置与状态提示，刷新后接待室设备清单、套用记录与设备实际归属保持一致。

## 技术栈

- 前端：Vue 3、Vite、Element Plus、Axios
- 后端：Spring Boot 3.3、JDK 17、MyBatis Plus、Redis
- 数据库：MySQL 8.0
- 部署：Docker Compose

## Docker 构建说明

前端、后端 Dockerfile 均保留依赖层缓存；Docker Compose 使用 `.env` 中的固定端口，并绑定到 `127.0.0.1`，避免对外暴露和端口漂移。

## 常见问题

- 后端编译失败时先执行 `mvn -version` 检查 JDK，再检查 Lombok、Maven 编译插件和 `pom.xml` 是否被忽略。
- 前端构建失败时优先按实际报错检查 import 路径、导出名、Vite 代理端口和构建期语法。
- 页面中文乱码时检查源码、SQL 初始化脚本、数据库字符集、连接串编码和已有 Docker volume 数据；初始化 SQL 已增加 `SET NAMES utf8mb4;`。
